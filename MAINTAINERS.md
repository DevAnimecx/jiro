## Release process

1. Features/fixes land on `main` via PR (requires passing CI + review).
2. Releases are tagged `vX.Y.Z` following [Semantic Versioning](https://semver.org/).
3. Changelog is updated in `CHANGELOG.md` before each tag.
4. Packages are published to PyPI (`jiro-search`) and GitHub Container Registry
   (`ghcr.io/devanimecx/jiro`) via GitHub Actions.

## Governance

Jiro is MIT-licensed and community-driven. Significant direction changes
(open-core roadmap, new editions) are proposed in GitHub Discussions before
implementation.
