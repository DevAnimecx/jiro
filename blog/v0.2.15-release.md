# Jiro v0.2.15 — The Complete Release

**Published: September 10, 2026**

We're thrilled to announce Jiro v0.2.15 — the most comprehensive release yet! This version combines everything from v0.2.13, v0.2.14, and v0.2.15 into one massive update with official SDKs, real-time streaming, batch operations, and enterprise-grade monitoring.

## What's New

### Official SDKs

We've released official SDKs for the three most popular languages:

#### Python SDK
```bash
pip install jiro-sdk
```

```python
from jiro_sdk import JiroClient

client = JiroClient(api_key="your-key")
results = client.search("python web scraping")
content = client.scrape("https://example.com")
answer = client.ai_ask("What is Python?")
```

**Features:**
- Sync & async clients
- Full API coverage
- Type hints and docstrings
- Context manager support
- WebSocket streaming

#### JavaScript/TypeScript SDK
```bash
npm install jiro-sdk
```

```javascript
import { JiroClient } from 'jiro-sdk';

const client = new JiroClient({ apiKey: 'your-key' });
const results = await client.search('python web scraping');
const content = await client.scrape('https://example.com');
const answer = await client.aiAsk('What is Python?');
```

**Features:**
- Browser & Node.js compatible
- Full TypeScript support
- WebSocket streaming
- ESM & CommonJS exports

#### Go SDK
```bash
go get github.com/DevAnimecx/jiro/sdk/go
```

```go
import "github.com/DevAnimecx/jiro/sdk/go"

client := jiro.NewClient(jiro.WithAPIKey("your-key"))
results, _ := client.Search("python web scraping", nil)
content, _ := client.Scrape("https://example.com", nil)
answer, _ := client.AiAsk("What is Python?", nil)
```

**Features:**
- Idiomatic Go style
- Functional options pattern
- Context support
- Error handling with custom errors

### WebSocket Streaming

Real-time search results via WebSocket:

```javascript
const ws = new WebSocket('ws://localhost:8000/ws/search?query=AI+news');
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(data);
};
```

**Endpoints:**
- `/ws/search` — Single query streaming
- `/ws/search/stream` — Continuous streaming
- `/ws/monitor` — System metrics

### Batch Operations

Execute multiple searches and scrapes concurrently:

```python
# Batch search
job = client.batch_search(
    queries=["python", "javascript", "go"],
    engine="google",
    num_results=5
)

# Batch scrape
job = client.scrape_batch([
    "https://example.com",
    "https://httpbin.org/html"
])
```

### Stealth Engine

Bypass anti-bot detection with TLS/JA3 fingerprint rotation:

```python
from jiro.stealth import StealthClient

client = StealthClient()
results = client.search("protected site")
```

**Features:**
- 20+ browser impersonation profiles
- TLS fingerprint rotation
- Behavioral simulation
- curl-cffi integration

### Monitoring & Observability

Enterprise-grade monitoring with Prometheus metrics:


**Features:**
- Request tracing with correlation IDs

### Advanced Caching

LRU/LFU caching with analytics:

```python
from jiro.cache_advanced import CacheManager

cache = CacheManager(strategy="lru", max_size=1000)
results = cache.get("query:python")
```

**Features:**
- LRU and LFU strategies
- Cache analytics (hit rate, miss rate)
- TTL support
- Memory usage tracking

### Search History & Analytics

Track and analyze your search patterns:

```python
# Get search history
history = client.get_history(days=30)

# Get analytics
analytics = client.get_analytics()
print(f"Popular queries: {analytics.popular_queries}")
```

### Export/Import

Export your data in multiple formats:

```python
client.export_results("results.csv", format="csv")

client.export_results("results.md", format="markdown")
```
